AUTHENTICATION FLOW
═════════════════════════════════════════════════════════════════

    User opens Telegram Bot
           │
           ├─→ [Web App button]
           │
           ↓
    Browser loads index.html
           │
           ├─→ Loads Supabase SDK
           ├─→ Loads auth.js module
           ├─→ Calls TelegramAuth.init()
           │
           ↓
    Telegram.WebApp.ready()
           │
           ├─→ Gets initDataUnsafe.user
           │   (id, username, first_name, etc)
           │
           ↓
    Search: profiles WHERE telegram_id = ?
           │
           ├─→ [NOT FOUND]
           │   └─→ NEW USER FLOW
           │
           ├─→ [FOUND]
           │   └─→ EXISTING USER FLOW
           │
           ↓
    Fetch all profile data
           │
           ├─→ profiles
           ├─→ player_balances
           ├─→ player_settings
           ├─→ player_vip
           │
           ↓
    Save to localStorage
           │
           ├─→ Cache for offline access
           │
           ↓
    Dispatch 'telegramAuthReady'
           │
           ├─→ Event bubbles to all listeners
           │
           ↓
    UI updates with REAL data
           │
           ├─→ Profile nickname
           ├─→ Level & experience
           ├─→ Cash balance
           ├─→ VIP status
           ├─→ Avatar image
           │
           ↓
    ✓ USER LOGGED IN


NEW USER FLOW
═════════════════════════════════════════════════════════════════

    Telegram ID not found
           │
           ↓
    Generate nickname: Player_<telegram_id>
           │
           ↓
    CREATE profiles
    ├─ telegram_id ← from Telegram
    ├─ telegram_username
    ├─ first_name
    ├─ last_name
    ├─ avatar_url
    ├─ nickname ← auto-generated
    ├─ level = 1
    ├─ experience = 0
    ├─ status = 'online'
    ├─ is_verified = false
    ├─ is_banned = false
    ├─ is_deleted = false
    │
    ├─→ ⚠️ If duplicate (concurrent):
    │   └─→ UNIQUE constraint fires
    │   └─→ Catch error
    │   └─→ Fetch existing profile
    │   └─→ Continue normally
    │
    ↓
    Get new uid from profiles
           │
           ↓
    CREATE player_balances
    ├─ uid (from profiles)
    ├─ cash = 0
    ├─ bank = 0
           │
           ↓
    CREATE player_settings
    ├─ uid
    ├─ notifications_enabled = true
    ├─ chat_notifications = true
    ├─ sound_enabled = true
           │
           ↓
    CREATE player_vip
    ├─ uid
    ├─ vip_level = 0
    ├─ expires_at = NULL
           │
           ↓
    ✓ NEW PLAYER CREATED


EXISTING USER FLOW
═════════════════════════════════════════════════════════════════

    Telegram ID found
           │
           ├─→ Load profile record

           ↓
    Check flags
           │
           ├─→ is_banned = true?

           │

           │

               └─→ ✓ CONTINUE
           │
           ↓
    UPDATE profiles
    ├─ status = 'online'
    ├─ last_seen_at = NOW()
    ├─ updated_at = NOW()
           │
           ↓
    ✓ EXISTING PLAYER UPDATED

RLS POLICIES
═════════════════════════════════════════════════════════════════

Anonymous User (frontend) can:

    profiles:
    ├─ SELECT any row
    ├─ INSERT new profile
    └─ UPDATE status & last_seen_at
    
    player_balances:
    ├─ SELECT
    └─ INSERT
    
    player_settings:
    ├─ SELECT
    └─ INSERT
    
    player_vip:
    ├─ SELECT
    └─ INSERT

Anonymous User CANNOT:

    ✗ UPDATE balance
    ✗ UPDATE level/experience
    ✗ DELETE anything
    ✗ INSERT into money_transactions
    ✗ UPDATE is_banned/is_deleted
    
    (These need Edge Functions with service_role later)
