⏱️ ЧТО НУЖНО СДЕЛАТЬ (15 минут)

ШАГ 1: Конфигурация Supabase (5 минут)
──────────────────────────────────────

1. Открыть: https://app.supabase.com/
2. Выбрать свой проект
3. Settings → API
4. Скопировать:
   - Project URL → SUPABASE_URL
   - anon public → SUPABASE_ANON_KEY

5. В файле index.html (около строки 330):
   Найти:
   TelegramAuth.setConfig({
     supabaseUrl: 'https://xxxxx.supabase.co',
     supabaseAnonKey: 'your-anon-key-here',
   });
   
   Заменить на СВОИ значения

6. Повторить то же самое в profile.html (около строки 350)

⚠️ ВАЖНО: Это PUBLIC ключи (anon). Безопасно иметь в коде.
          НИКОГДА не кладите service_role_key в frontend!


ШАГ 2: Создание RLS политик в Supabase (5 минут)
──────────────────────────────────────────────────

1. Открыть Supabase Dashboard
2. SQL Editor → New Query
3. Скопировать весь содержимый файла: TELEGRAM_AUTH_SUPABASE.sql
4. Вставить в SQL Editor
5. Нажать Run

Должны создаться 6 RLS политик для:
- profiles (INSERT, SELECT, UPDATE)
- player_balances (INSERT)
- player_settings (INSERT)
- player_vip (INSERT)

✅ ГОТОВО!


ШАГ 3: Создание Telegram бота и развёртывание (5 минут)
─────────────────────────────────────────────────────────

1. Открыть Telegram → Search: @BotFather
2. Send: /newbot
3. Выбрать имя бота и username
4. Получить TELEGRAM_BOT_TOKEN (сохранить на потом)

5. Отправить: /setmenubutton
6. Выбрать свой бот
7. Выбрать: Web App
8. Установить URL на свой GitHub Pages домен
   Пример: https://yourusername.github.io/Black%20Russia%20Online/

9. Commit и push в GitHub:
   git add .
   git commit -m "Add Telegram authentication"
   git push origin main

✅ ГОТОВО! Сайт автоматически обновится на GitHub Pages.


ШАГ 4: Тестирование (2 минуты)
───────────────────────────────

1. Открыть Telegram
2. Найти свой бот
3. Нажать кнопку Web App
4. Должны увидеть автоматический вход и реальные данные профиля

✅ ВСЁ РАБОТАЕТ!

💻 ИСПОЛЬЗОВАНИЕ В ДРУГИХ СТРАНИЦАХ

На странице market.html, chat.html, games.html добавить:

```html
<head>
  <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
  <script src="js/auth.js"></script>
</head>

<body>
  <!-- Your page content -->

  <script>
    (async () => {
      TelegramAuth.setConfig({
        supabaseUrl: 'https://your-url.supabase.co',
        supabaseAnonKey: 'your-key-here',
      });

      await TelegramAuth.init();

      if (!TelegramAuth.isAuthorized()) {
        alert('Please login first');
        location.href = 'index.html';
        return;
      }

      const profile = TelegramAuth.getProfile();
      console.log('Hello', profile.nickname);
    })();
  </script>
</body>
```

Полные примеры: TELEGRAM_AUTH_INTEGRATION_EXAMPLES.html

🛠️ API ДЛЯ РАЗРАБОТЧИКОВ

// Инициализация
await TelegramAuth.init();

// Проверка авторизации
TelegramAuth.isAuthorized()          // true/false
TelegramAuth.isBanned()              // true/false
TelegramAuth.isDeleted()             // true/false

// Получение данных
TelegramAuth.getCurrentUser()        // Telegram данные
TelegramAuth.getCurrentProfile()     // Полный профиль
TelegramAuth.getProfile()            // Только профиль
TelegramAuth.getBalance()            // { cash, bank }
TelegramAuth.getVip()                // { vip_level, expires_at }
TelegramAuth.getSettings()           // Настройки

// Выход
TelegramAuth.logout();

// События
document.addEventListener('telegramAuthReady', (e) => {
  // UI готов с реальными данными
  console.log(e.detail.profile);
});

🐛 ЕСЛИ ЕСТЬ ОШИБКИ

"Supabase SDK not loaded"
→ Убедитесь, что Supabase script в HEAD ДО auth.js

"No Telegram user available" (в браузере)
→ Нормально. Telegram WebApp работает только внутри Telegram.
→ В Telegram будет работать.

"RLS Policy Error"
→ Запустите SQL из TELEGRAM_AUTH_SUPABASE.sql

"UNIQUE violation"
→ Обработано автоматически. Два одновременных входа = один аккаунт.

Неправильные credentials
→ Скопируйте из Settings → API
→ Используйте "anon public", НЕ "service_role_key"

Подробнее: см. TELEGRAM_AUTH_GUIDE.md раздел "Troubleshooting"
