🚀 САМЫЙ БЫСТРЫЙ СТАРТ (3 ШАГА - 15 МИНУТ)

ШАГ 1: Конфигурация (5 минут)
──────────────────────────

  1. Открыть: https://app.supabase.com/
  2. Settings → API
  3. Скопировать Project URL
  4. Скопировать anon public key
  5. Заменить в index.html строку:
     TelegramAuth.setConfig({
       supabaseUrl: 'ВСТАВИТЬ ЗДЕСЬ',
       supabaseAnonKey: 'ВСТАВИТЬ ЗДЕСЬ',
     });
  6. Повторить для profile.html

ШАГ 2: RLS Политики (5 минут)
──────────────────────────────

  1. Supabase Dashboard → SQL Editor
  2. Скопировать весь файл: TELEGRAM_AUTH_SUPABASE.sql
  3. Вставить в SQL Editor
  4. Нажать Run

ШАГ 3: Telegram + Deploy (5 минут)
───────────────────────────────────

  1. Telegram → @BotFather → /newbot
  2. Выбрать имя бота
  3. /setmenubutton → установить Web App URL
  4. git push в GitHub
  
  Готово!
